# Онлайн-касса кинотеатра

Учебный проект по дисциплинам «Разработка серверной части Веб-приложения (backend)» и «Разработка клиентской части Веб-приложения (frontend)».
Система автоматизирует онлайн-продажу билетов в кинотеатре: от просмотра афиши до получения электронного билета с QR-кодом.

## Возможности

- просмотр афиши фильмов и сеансов;
- выбор мест на интерактивной схеме зала;
- временное резервирование мест (15 минут);
- эмуляция оплаты банковской картой;
- генерация электронного билета с QR-кодом;
- отправка билета на email через сервис уведомлений;
- административная панель: фильмы, залы, сеансы, цены;
- отчёты по продажам и аудиторский журнал операций.

## Стек

- Backend: Python, FastAPI
- Frontend: React / Vue.js
- База данных: PostgreSQL 14+
- Кэш: Redis
- API: REST, OpenAPI 3.0
- Развёртывание: Docker, docker-compose

## Архитектура

Модульный монолит. Внутри backend выделены модули информации и резервирования, оплаты и уведомлений. Единая база данных PostgreSQL.

## Документация

- SRS — спецификация программных требований
- BPMN-диаграмма — процесс покупки билета
- C4-диаграмма — уровни 1–2
- ER-диаграмма — структура базы данных
